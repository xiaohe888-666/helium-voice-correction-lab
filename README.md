# 氦语音矫正实验台

直接双击 `index.html` 即可打开。音频处理和导出均在本机浏览器内完成，不会上传录音。

## 建议演示顺序

1. 点击“载入示例”。
2. 依次播放“正常参考”和“畸变输入”，听共振峰位置差异。
3. 播放“矫正输出”，查看下方频谱中橙色峰值是否向青色参考峰靠近。
4. 改变“声速比 CR”，或直接在频率映射图中拖动锚点。
5. 调整“包络平滑”和“高频恢复”后，再点击“应用矫正”。
6. 点击“导出 WAV”保存处理结果。

如需处理真人录音，点击“选择文件”或将音频拖入页面。麦克风功能在部分浏览器中对本地 `file://` 页面有限制，此时优先使用文件上传。

## 方法边界

网页采用短时傅里叶变换，分别处理频谱包络与原始相位，使共振峰位置向正常语音移动，同时尽量保持基频和时间长度。内置示例是合成元音序列，只用于方法验证，不代表真实潜水员语音数据。

论文中的 GRNN 矫正模型依赖成对的“面罩畸变语音 / 正常语音”训练数据。本网页没有伪造该训练集，也没有把二维分类演示冒充为语音重建系统。
